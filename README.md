# Disease Detector

Aplikasi prediksi penyakit berdasarkan gejala menggunakan Machine Learning, dengan rekomendasi dokter spesialis.

## 🔗 Demo Live
Coba langsung di: https://jsnaldr.pythonanywhere.com

## Fitur
- Input gejala lewat checkbox
- Prediksi penyakit menggunakan Random Forest
- Rekomendasi dokter spesialis
- Deskripsi & saran pencegahan penyakit

## Tech Stack
- Python, Flask
- scikit-learn, pandas
- HTML, CSS, JavaScript
